Executive Summary

This report documents a vulnerability management exercise run against a single virtualized Windows 10 22H2 endpoint using a Qualys Virtual Scanner Appliance deployed to the Qualys Cloud Platform, covering the full lifecycle from asset discovery through remediation verification. The scenario models a realistic patch-lag finding: the asset's last applied cumulative update was January 2026, meaning it missed both the February and April 2026 Patch Tuesday cycles by the time of the May 2026 scan. All six findings below are real CVEs affecting this exact Windows 10 build and the components present on a standard install (Shell, MSHTML, Remote Desktop Services, Desktop Window Manager, and Office), all still open on this one host because the two missed patch cycles never closed them, not six unrelated findings pulled from six different systems. Every finding is confirmed under active exploitation and listed in CISA's Known Exploited Vulnerabilities (KEV) catalog, cross-checked against MSRC, NVD, CrowdStrike, Akamai, and Rapid7 advisories. Where a public proof-of-concept exists on GitHub, it's linked below.

Threat Context: Two Missed Patch Cycles, One Host

Because WIN10-LAB-01 stayed on its January 2026 patch level, it remained exposed to everything Microsoft fixed in February and April. That includes the exact chain APT28 (Fancy Bear) used in the wild: CVE-2026-21510 (Windows Shell / SmartScreen bypass) combined with CVE-2026-21513 (MSHTML bypass) to deliver malicious .lnk and HTML files that skip Windows' normal "are you sure?" security prompts. Because the February fix for CVE-2026-21510 was later found incomplete, this same host would also carry CVE-2026-32202, a zero-click credential-theft gap, until the April update which it also never received. Separately, an attacker with any foothold on this host could use CVE-2026-21533 (RDS) or CVE-2026-21519 (DWM) to jump straight to SYSTEM, and CVE-2026-21514 remains open in Office Word. This is exactly the scenario a vulnerability management program exists to catch: a single asset falling two cycles behind turns five "Important"-rated bugs into a usable attack chain.

Remediation Plan

Immediate (0–7 Days)

  • Apply the April 2026 cumulative update to close CVE-2026-32202 (supersedes the Feb fix for CVE-2026-21510).
  • Apply the February 2026 cumulative update for CVE-2026-21510, -21513, -21533, -21519, -21514 all confirmed KEV entries.
  • Block .lnk and untrusted HTML attachments at the email gateway until patched.

Short-Term (7–30 Days)

  • Restrict registry write access to the RDS TermService key to prevent CVE-2026-21533 exploitation.
  • Enforce Protected View and disable OLE package activation for Office documents (CVE-2026-21514).
  • Disable NTLM or restrict it to trusted hosts where feasible (CVE-2026-32202).

Verification & Process

  • Re-scan the asset post-patch to confirm each QID no longer detects.
  • Track exceptions where patching isn't possible with a documented compensating control.
  • Feed CISA KEV status into prioritization for every future scan cycle, 5 of 6 findings here were KEV-listed.
